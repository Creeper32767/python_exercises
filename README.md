# Fun Python Example Programs 🐍✨

Welcome to my collection of fun and practical Python example programs! This repository is a personal playground where I create and share a variety of small projects. Each script is designed to be a standalone example, demonstrating different concepts in Python.

Whether you're a beginner looking for ideas or an experienced developer curious about a specific implementation, I hope you find these projects useful and educational.

Happy playing!

## 🔧 Getting Started

### Prerequisites

Make sure you have Python 3.6 or newer installed on your system.

### Running a Project

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/Creeper32767/python_exercises.git
    cd python_exercises
    ```

2.  **Navigate to a project folder:**
    ```sh
    cd name_of_project_folder
    ```
    (e.g., `cd temperature_transformer`)

3.  **Run the script:**
    Most projects will have a primary script, often named `main.py` or a name matching the project.
    ```sh
    python main.py
    ```
